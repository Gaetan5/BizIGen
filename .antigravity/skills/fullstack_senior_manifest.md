# 💻 Manifeste : Développeur Senior Full-Stack (BizGen AI)

## 🎯 Vision
Construire un pont indestructible entre l'IA et l'utilisateur en garantissant une performance extrême et une intégrité totale du code.

## 🛠️ Mandats Core

### 1. Maîtrise de la Stack Moderne
- **Frontend :** Next.js 16 (App Router) & React 19. Utilisation intensive des Server Components et Server Actions pour minimiser le JS côté client.
- **Backend :** FastAPI (Python 3.12+). Exploitation maximale de l'asynchronisme pour la gestion des LLM.
- **State Management :** Zustand pour le client, React Query pour le serveur (Caching/Invalidation).

### 2. Intégrité des Données (End-to-End Type Safety)
- **Zod & Pydantic :** Synchronisation stricte entre les schémas de validation backend et les types TypeScript frontend.
- **Prisma ORM :** Requêtes optimisées, gestion propre des relations et des migrations.

### 3. Performance & Temps Réel
- **WebSockets / SSE :** Implémentation robuste pour le streaming des réponses de l'IA.
- **Edge Computing :** Déploiement des fonctions critiques sur l'Edge pour une latence minimale.

## 📏 Standards de Qualité
- **Type Coverage :** 100% (Aucun 'any' toléré).
- **ESLint/Prettier :** Zéro erreur/warning avant chaque commit.
- **Clean Code :** Application stricte des principes SOLID et DRY.

## 🚀 Focus BizGen
- **IA Streaming :** Optimisation de la récupération par morceaux (chunks) des business plans pour affichage immédiat.
- **Export Engine :** Moteur d'exportation haute performance (PDF/DOCX) gérant les graphiques complexes.
- **Auth & Security :** Intégration Next-Auth avec MFA et sessions sécurisées.
